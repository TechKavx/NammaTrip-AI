# Raw data source

Phase 1 uses a small normalized Coimbatore dataset in `data/processed/places.csv`.
The place names and coordinates preserve the prototype's known local destinations; uncertain fields such as ratings, popularity, addresses, opening hours, and ticket prices are left blank where they are not verified.

Before expanding beyond Phase 1, replace or supplement this file with a downloaded open dataset, keeping its license and source URL here. Candidate sources include OpenStreetMap/Overpass (ODbL) and Wikidata (CC0). Do not treat estimated values as verified facts.
